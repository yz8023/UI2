06 · 热区与误触
02:26 原视频 ↗
Bilibili · KD一对A · 触控体验 · 热区

为什么你总是点不中那个按钮

图标画得多精致，热区就跟着缩多小——这是最容易翻车的地方。这一页让你用鼠标亲手体验一次「点不中」，再看三招怎么救。

热区 / Fitts 误触 / 触感反馈 2026-10-27
「视觉 16，热区从 40 起、最小 28；两个热区之间必须留缝，可滑动区旁边留 20dp。」
演示 01

命中测试：同样 16px 的图标，热区差一倍

两边各点 8 个点，看你能漏多少次。可以打开「显示热区」看清楚差别。

✕ 热区 = 图标大小命中 0 / 0

鼠标稍微抖一下就打空——手指只会更糟。

✓ 热区 44px命中 0 / 0

图标还是 16px，但可点区域扩大到 44px，几乎不会失手。

演示 02

两个热区挨在一起，等于开了一个隧道

两边都想点「编辑」，看误触发生在哪里。

✕ 热区紧贴误触 0 次

两片可点区域直接相接，手指落在缝上就会被判给错误的那一个。

✓ 中间留 8px 缝误触 0 次

缝里点到就什么都不会发生，比点错安全得多。

演示 03

滑动区会偷走点击

在卡片上按住横拖。左边的「收藏」会被滑动手势误触发，右边加了位移阈值。

✕ 不判断位移误收藏 0 次
旅行灵感12 张图
周末露营8 张图

手指从按钮上起势去滑，松手时 click 照样会来一下。

✓ 位移 > 8px 就取消误收藏 0 次
旅行灵感12 张图
周末露营8 张图

只有「按下 → 松开」几乎没移动时才算一次点击，滑动就纯粹是滑动。

演示 04

看不见的反馈：让手指知道「点到了」

手指盖住按钮时，视觉反馈是看不见的，只能靠触感。

视觉脉冲 + navigator.vibrate(12)

iOS 用 Taptic Engine，安卓用 vibrate；只给 10~15ms，别做成嗡嗡长震。

这期视频的要点

  • 视觉 16，热区 40 起：图标可以画得很小，可点区域至少要 40px，底线 28px。
  • 热区之间留缝：两片可点区域紧贴，等于给误触开了一条隧道。
  • 滑动区旁边留 20dp：别让横滑手势偷走点击，用位移阈值判断是滑还是点。
  • 手指会挡住画面：看不见视觉反馈时，靠 10~15ms 的触感告诉用户「点到了」。
  • Fitts 定律：目标越大、距离越近，命中越快；把高频操作放在拇指自然落点。
