# UI 素材库 2.0 · 46 条素材

一个 App 从组件到页面所需的全部界面素材：**每条素材 = 可运行演示 + 实现方案 + 参考来源 + 环境要求 + 一键复制提示词**。

## 打开方式

- 直接双击 `index.html`（不需要服务器；离线可用，无任何 CDN / 字体 / 图片依赖）。
- 卡片可点，右侧滑出详情：效果 / 机制 / 判据 / 代码 / 提示词 / 出处，六个面板。
- 键盘：`Esc` 关闭，`←` `→` 切换上一条 / 下一条。
